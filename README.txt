
=== Farhat Video Q&A (MVP) ===
Contributors: farhat
Requires at least: 6.0
Tested up to: 6.6
Stable tag: 0.1.0

Per-video Q&A from Vimeo transcripts using RAG. English only. Floating chat bubble on video pages.

== Installation ==
1. Upload the 'farhat-video-qa' folder to /wp-content/plugins/.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to 'Video Q&A' in the admin sidebar and enter your Vimeo Access Token and OpenAI API Key.

== Usage ==
- Embed a Vimeo video in a page; the bubble appears automatically.
- Or use [farhat_video_qa id="123456789"].
